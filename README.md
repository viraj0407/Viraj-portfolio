# Viraj Chavan — AI & Data Science Portfolio

A premium, responsive React + Vite personal portfolio focused on AI, machine learning, data science, analytics, and decision science.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Edit personal links

Open `src/App.jsx` and update the `PROFILE` object:

- `github`
- `linkedin`
- `email`
- `phone`

Project GitHub/live-demo URLs are intentionally placeholders (`#`) because no project URLs were supplied. Replace them in the `projects` array.

## Contact form

The contact form is UI-only. Connect it to your preferred form/email/API provider before production deployment.

## Content policy

The site uses only the supplied portfolio information and does not add certifications, awards, companies, testimonials, client names, or unsupported achievements.
